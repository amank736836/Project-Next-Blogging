# Run summaries

Empty for the same reason as [../historical/](../historical/README.md): a cross-run rollup
needs more than one run.

The intended shape is one row per run — date, totals, pass rate, verdict — so a reader can see
the trend without opening each record. With a single data point that table would be one row
duplicating [../latest/execution-RUN-2026-10-07-001.md](../latest/execution-RUN-2026-10-07-001.md).
